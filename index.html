Desktop • WPF / MVVM

Booking Desktop Client (WPF)

Многопоточное многооконное клиентское десктоп-приложение для управления бронированиями с архитектурой MVVM.

  • Построена чистая MVVM архитектура с использованием Microsoft Community Toolkit (`ObservableObject`, `RelayCommand`, `ObservableProperty`).
  • Реализована плавная навигация через `ContentControl` и сервисный слой, предотвращающая пересоздание тяжелых оконных инстансов.
  • Неблокирующее взаимодействие с бэкендом через асинхронные HTTP-вызовы в фоновых потоках.
  • Генеративные AI-инструменты применены для быстрой верстки XAML и генерации шаблонных ViewModel.
